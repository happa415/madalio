# Madalio v1.40

日付付きのメモをブラウザ内に保存できる、シンプルなWebアプリです。

Madalioという名前は、タガログ語で「簡単」を意味する「Madali」から着想を得ています。

## 主な機能

- 日付と内容を指定して記録を保存
- 日付が新しい順に記録を表示
- 記録内容のコピー
- 保存済み記録の編集・削除
- 作成日時と最終編集日時の表示
- `localStorage`への自動保存
- CSV形式での書き出し
- CSVファイルからの読み込み
- 読み込み時の重複スキップ
- スマートフォン表示への対応

## 使い方

### 起動

外部ライブラリやビルド作業は必要ありません。`index.html`をブラウザで開くと利用できます。

ブラウザの制限により一部の機能が動作しない場合は、このディレクトリでローカルWebサーバーを起動してください。例えばPythonがインストールされている環境では、次のコマンドを使用できます。

```sh
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開きます。

### 記録する

1. 日付を選択します。初期状態では今日の日付が設定されています。
2. 内容を入力します。
3. 「保存する」を押します。

記録一覧では、各記録に次の操作ボタンが表示されます。

- 「コピー」：記録内容をクリップボードにコピーします。
- 「編集」：日付と内容を編集します。
- 「削除」：確認後に記録を削除します。

## バックアップ

### 書き出し

- 「CSV保存」：日付と内容を表形式で保存します。Excelなどで開けるよう、UTF-8のBOMを付けています。

### 読み込み

- このアプリから書き出したCSVファイルに対応しています。
- 読み込んだ記録は既存の記録を消さずに追加されます。
- 「日付」と「内容」が両方同じ記録は重複として除外されます。
- 読み込み時には、新しく追加される件数を確認してから処理します。

書き出しファイルにはID、作成日時、編集日時は含まれません。読み込んだ記録には、読み込んだ時点の新しいIDと作成日時が設定されます。

## データの保存について

記録は、利用中のブラウザの`localStorage`に保存されます。サーバーへの送信や、別のブラウザ・端末との自動同期は行いません。

次の操作によって記録が失われる可能性があります。

- ブラウザのWebサイトデータや閲覧データを削除する
- プライベートブラウズなど、データを永続保存しないモードを利用する
- 別のブラウザ、端末、ホスト名またはポート番号からアプリを開く

大切な記録は、定期的にCSVでバックアップしてください。
