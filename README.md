# Madalio v1.3.0

日付つきのメモをブラウザ内に保存する、シンプルなWebアプリです。

Madalio は、タガログ語で「簡単」を意味する「Madali」から着想を得た名前です。

## 機能

- 日付・内容のリアルタイム検索

- 日付と内容を保存
- 新しい記録を上に表示
- 記録を編集
- 記録を1件ずつ削除
- localStorageへ保存
- TXT形式で書き出し
- CSV形式で書き出し
- TXT・CSVファイルから読み込み
- 読み込み時の重複スキップ
- スマートフォン対応

## インポート仕様

- 現在の記録を消さずに追加します。
- 「日付」と「内容」が同じ記録は重複として除外します。
- このアプリから書き出したTXT・CSVに対応しています。

## 注意

- 記録内容は、利用したブラウザのlocalStorageに保存されます。
- SafariのWebサイトデータを削除すると、記録も消える場合があります。
- 大切な記録は、定期的にTXTまたはCSVでバックアップしてください。
- 別のブラウザや別の端末とは自動同期されません。


## v1.3.0で追加

- 検索ボックスへ入力すると、日付と本文からリアルタイムで絞り込みます。
- 検索結果件数を「該当件数 / 全件数」で表示します。
- 検索文字は保存されません。
