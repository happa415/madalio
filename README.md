# かんたん記録帳

日付つきのメモをブラウザ内に保存する、シンプルなWebアプリです。

## 機能

- 日付と内容を保存
- 新しい記録を上に表示
- 記録を1件ずつ削除
- localStorageへ保存
- TXT形式で書き出し
- CSV形式で書き出し
- スマートフォン対応

## 使い方

1. `index.html` をブラウザで開きます。
2. 日付と内容を入力して「保存する」を押します。
3. 必要に応じて「TXT保存」または「CSV保存」を押します。

## 注意

- 記録内容は、利用したブラウザのlocalStorageに保存されます。
- ブラウザのWebサイトデータを削除すると、記録も消える場合があります。
- 大切な記録は、定期的にTXTまたはCSVでバックアップしてください。
- 別のブラウザや別の端末とは自動同期されません。
